# Logotipos na faixa do rodapé

Atualizado em 01/11/2026, conforme solicitação da loja para usar os logos, em vez dos nomes em uma fonte comum. A faixa usa arquivos locais com carregamento lazy e tons de cinza, fundo branco e links para os filtros das marcas. Ela aparece uma única vez em todas as páginas. O filtro monocromático é visual; os arquivos originais não foram redesenhados. Alt e nome acessível identificam a marca. Se uma imagem falhar, o nome é a alternativa. A faixa inclui somente marcas com logo cadastrado; entradas genéricas como “Marca não informada” não recebem logo inventado. Os filtros do catálogo continuam completos.
